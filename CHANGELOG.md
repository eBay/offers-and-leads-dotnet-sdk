# ChangeLog

## 0.5.0 (11/26/2026)

### Added

- Local mock servers: base URL properties accept plain `http` when the host is a loopback host (`127.0.0.1`, `::1` or `localhost`) that you also add to `OffersAndLeadsConfiguration.AllowedHosts`. Before, every base URL had to use HTTPS. Every other host still requires HTTPS. `OffersAndLeadsConfiguration.LoopbackHosts` lists the loopback hosts.

### Changed

- Hosts are compared case-insensitively and without IPv6 brackets, so `[::1]` and `::1` match.

## 0.4.0 (11/17/2026)

### Breaking changes

#### Removed StrawberryShake types

The typed GraphQL client is now generated by the SDK generator instead of StrawberryShake. Every type that `OfferGraphQLClient` accepts or returns keeps its name, namespace (`EBay.OffersAndLeads.Generated.GraphQL`) and members. The result interfaces, result classes, input classes and enums are unchanged. Only StrawberryShake's own plumbing is no longer public:

- `IOffersAndLeadsGraphQLClient`, `OffersAndLeadsGraphQLClient`, and the per-operation `I{Operation}Query`, `I{Operation}Mutation`, `{Operation}Query`, `{Operation}Mutation` and `{Operation}{Kind}Document` types
- `AddOffersAndLeadsGraphQLClient` (namespace `Microsoft.Extensions.DependencyInjection`). Use `AddOffersAndLeadsSdk`.
- the `EBay.OffersAndLeads.Generated.GraphQL.State` namespace, `{Enum}Serializer` and `{Input}InputValueFormatter`
- input classes no longer implement `State.I{Input}Info`

#### Simpler dependency injection

- `AddOffersAndLeadsSdk` now registers only the configuration and a singleton `OffersAndLeadsClient`. `ClassifiedLeadsClient`, `NegotiationClient` and `OfferGraphQLClient` are no longer registered individually: inject `OffersAndLeadsClient` and use its `ClassifiedLeads`, `Negotiation` and `GraphQL` properties.
- The SDK no longer uses `IHttpClientFactory` or registers named `HttpClient`s, and no longer depends on `Microsoft.Extensions.Http`. To customise HTTP (proxy, client certificates, test doubles), use the new `OffersAndLeadsClient(OffersAndLeadsConfiguration, HttpMessageHandler)` constructor.

#### Trusted hosts

- The client constructors throw `InvalidOperationException` when a base URL uses a host that is not trusted (see Security). Add such hosts, for example a proxy, to `OffersAndLeadsConfiguration.AllowedHosts`.

### Security

- The access token is sent only to trusted hosts. Before, it was attached to requests for any HTTPS host configured as a base URL.

### Added

- `OffersAndLeadsConfiguration.AllowedHosts` for additional hosts trusted with the access token, and `OffersAndLeadsConfiguration.DefaultAllowedHosts`. The eBay production hosts and their sandbox counterparts (for example `api.sandbox.ebay.com`) are trusted by default, so the sandbox needs no extra configuration.
- Target framework `net472` (.NET Framework 4.7.2).
- The Negotiation API (`OffersAndLeadsClient.Negotiation`, `NegotiationClient`, `OffersAndLeadsConfiguration.NegotiationBaseUrl`): `FindEligibleItemsAsync` and `SendOfferToInterestedBuyersAsync`. It moved here from the Communication SDK.
- Typed GraphQL operations work with the standalone `new OffersAndLeadsClient(config)` constructor. Before, they needed dependency injection.

### Changed

- Dependency minimums are lowered to the versions Kiota itself requires, so projects can keep older compatible versions: `Microsoft.Kiota.Bundle` >= 1.22.0 and `Microsoft.Extensions.DependencyInjection.Abstractions` >= 6.0.0. Previously the SDK required the newest 10.0.x packages. On .NET Framework the SDK requires `System.Text.Json` >= 10.0.0, matching the oldest supported .NET LTS (.NET 10). None of these minimums has a known vulnerability, and each release is tested at both the minimum and the latest versions.
- On .NET Framework the SDK's HttpClients allow 64 connections per host instead of the `ServicePointManager` default of 2.
- `OffersAndLeadsConfiguration.HttpTimeout` and `RequestOptions.Headers` have `set` accessors instead of `init`, so projects compiled with C# 7.3 can assign them. Existing source compiles unchanged; recompile code that was built against 0.3.0.
- `GraphQL.ExecuteRawUnsafeAsync` under dependency injection now throws `UnauthorizedException` for HTTP 401 and `GraphQLException` for other non-2xx responses. It used to throw a raw `HttpRequestException`. Standalone mode already behaved this way.

### Fixed

- A GraphQL input object with no properties set is sent as `{}` instead of `null`. Before, a call such as `SellerNegotiationHistoryAsync(new SellerNegotiationHistoryInput())` failed because eBay rejects `null` for a required input. Passing `null` itself works as before: it is sent as `null` where the operation accepts it and rejected where it doesn't.
